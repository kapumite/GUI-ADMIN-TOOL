# 🖥️ Система управления компьютерным классом

Простая программа для учителя, чтобы видеть экраны учеников, раздавать файлы и собирать работы.  
**Всё через удобную графическую панель — никакого Telegram!**

---

## 📁 Что в папке?

Внутри папки уже есть всё нужное:
📁 classroom/
├── 📄 teacher_gui.py ← программа для учителя (графическая панель)
├── 📄 student_agent_v2.py ← программа для учеников
├── 📄 config.py ← настройки (поправить один раз)
├── 📁 python/ ← уже есть Python! ничего устанавливать не надо
├── 📄 запуск_учителя.bat ← запустить учителя (двойной клик)
├── 📄 запуск_агента.bat ← запустить ученика (двойной клик)
├── 📄 get-pip.py ← для установки библиотек
└── 📁 received_works/ ← сюда будут сохраняться работы учеников

---

## ⚡ Первый запуск (только один раз)

### Шаг 1. Распаковать архив

Распакуй архив в любую папку на компьютере.  
Например, на рабочий стол.

---

### Шаг 2. Установить библиотеки (один раз)

Внутри папки есть уже готовый **переносимый Python** — в папке `python\`.  
Но для работы программы нужны дополнительные библиотеки.

#### Как их установить:

1. Открой папку с программой.
2. Нажми правой кнопкой мыши на свободное место → выбери **"Открыть в терминале"** или **"Командная строка"**.
3. Скопируй и вставь эту команду (установит менеджер пакетов pip):

```cmd
если обычный python
python get-pip.py
если используешь powershell
.\python\python.exe get-pip.py
если использовать портативный python который включен в сборку проекта
python\python.exe get-pip.py
```
4. Дождись окончания установки.
5. Теперь установи нужные библиотеки: (откройте командную строку и вставьте команду)
   pip install -r requirements.txt


▶️ Как запустить
Учительская программа
зайди в папку TeacherPanel
Просто дважды кликни по файлу: запуск.bat
Откроется красивое окно с панелью управления.

Ученическая программа
зайти в папку AGENT
Просто дважды кликни по файлу: запуск.bat на устройстве ученика
Откроется чёрное окно с логами — это нормально. Не закрывай его!

🌐 Настройка сети (самое важное!)
Шаг 1. Узнать IP учителя

    На компьютере учителя открой командную строку (Win + R → cmd → Enter).

    Напиши команду:

cmd

ipconfig

    Найди строчку "IPv4-адрес" — она выглядит как 192.168.1.121.

    Запомни эти цифры. 
    #это не обязательно так как прогграмма сканирует автомотически. нужно сделать вручную только если программа столкнулась с ошибкой и не смогла сделать сама
    Шаг 2. Вписать IP в настройки

Открой файл config.py блокнотом и найди строчку:
python

TEACHER_IP = "192.168.1.121"

Замени на свой IP-адрес. Например, если у тебя IP 192.168.0.15, то должно быть:
python

TEACHER_IP = "192.168.0.15"

🖥️ Как запускать на компьютерах учеников
Способ 1. Скопировать всю папку (проще)

    Скопируй всю папку с программой на флешку.

    На компьютере ученика скопируй папку на рабочий стол.

    Поправь в config.py только IP учителя (как написано выше).

    Запусти запуск_агента.bat.

Способ 2. Сделать один .exe файл (для удобства)

Чтобы ученикам не нужно было копировать всю папку, можно сделать один файл.
Что делаем:

    Открой командную строку в папке с программой.

    Установи PyInstaller (если не установлен):

cmd

python\python.exe -m pip install pyinstaller

    Сделай .exe файл для ученика:

cmd

python\python.exe -m PyInstaller --onefile --noconsole student_agent_v2.py

    Готовый файл появится в папке dist\ — он называется student_agent_v2.exe.

Теперь ученикам можно дать только этот один файл и config.py — и они смогут запустить агента без всей остальной папки.
📋 Порядок запуска

    Сначала запусти учительскую программу:


запуск.bat

    Потом на компьютерах учеников запусти:


запуск.bat

Или .exe файл, если скомпилировал.
🎮 Как пользоваться панелью учителя

После запуска откроется окно с вкладками:
Вкладка	Что делает
Панель управления	Список всех подключённых компьютеров с их статусом
Компьютеры	Таблица со всеми ПК, можно выбирать несколько
Наблюдение	Смотреть экраны учеников в реальном времени (нажми "Начать наблюдение")
Файлы	Раздавать файлы на все ПК и получать работы
Журнал	История всех команд и действий
Настройки	Можно сменить цвет интерфейса

❗ Если что-то не работает
Ошибка "Нет модуля PyQt6 / flask / requests"

Значит, библиотеки не установились. Попробуй запустить установку ещё раз:
cmd

python\python.exe -m pip install PyQt6 flask requests psutil Pillow

Агент не подключается к учителю

    Проверь, что в config.py у ученика правильный IP учителя.

    Проверь, что учительская программа запущена.

    Проверь, что брандмауэр Windows не блокирует порт 5001:

        Пуск → Брандмауэр Windows

        Разрешить приложение → добавить python.exe или teacher_gui.exe

    Проверь, что в config.py у ученика совпадает порт:

python

FLASK_PORT = 5001   # должен быть одинаковый у всех

Чёрное окно агента закрывается сразу

Запусти агента через командную строку, чтобы увидеть ошибку:
cmd

python\python.exe student_agent_v2.py
pause

Так ты увидишь текст ошибки и сможешь понять, что не так.
Не видно экраны учеников в "Наблюдении"

    Убедись, что на компьютере ученика есть библиотека Pillow:

cmd

python\python.exe -m pip install Pillow

    У некоторых систем могут быть проблемы с захватом экрана из-за разрешений.

💡 Советы

    Если не хочешь каждый раз открывать командную строку — просто используй .bat файлы, они уже есть в папке.

    .exe версию ученической программы можно скопировать на флешку и раздать ученикам — им не нужен будет весь остальной проект.

    Ученикам не нужен файл teacher_gui.py — только student_agent_v2.py и config.py.

🧪 Проверка работоспособности

Чтобы проверить, что всё установилось правильно, открой командную строку в папке с программой и напиши:
cmd

python\python.exe -c "import PyQt6, flask, requests, psutil, PIL; print('Всё готово!')"

Если напечатало Всё готово! — можно запускать.
